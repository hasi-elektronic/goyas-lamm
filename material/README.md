## logos/

⚠️ **Nicht auf die Website stellen, solange keine schriftliche Freigabe des Weinguts
vorliegt.** Fremde Wort-/Bildmarken auf einer gewerblichen Seite brauchen eine Erlaubnis; ein
zugeschicktes Logo ist noch keine. Und selbst mit Freigabe: Allmendinger allein neben Faigle
und den Weingärtnern hinzustellen sieht nach bezahlter Werbung aus — dann bräuchte es die
Logos der anderen Winzer auch.

Erlaubt ist, was jetzt schon passiert: die Winzer **im Text namentlich nennen**
(`public/restaurant.html`, digitale Speisekarte). Das ist eine Tatsachenbehauptung über das
eigene Angebot, keine Markennutzung.
